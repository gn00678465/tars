# Learning How to Learn

提供學習方法與每個方法的研究依據，用於回答「怎麼讀」「怎麼記」「讀了就忘」「某個學習方法有沒有用、為什麼有效」，也供讀書計畫選方法。排讀書計畫、備考、檢查學習進度的流程在 `tars-mode` skill 的 `playbooks/learn.md`；讀教材用 `tars ingest`。還沒有教材與期限的學習起點規劃（例如「我想學 Rust」）與覆盤用 `playbooks/coach.md`。語氣與邊界來自 session 開始帶進來的 `<soul>` 區塊。

依據是 repo 的 `docs/research/learning-how-to-learn.md`（Coursera「Learning How to Learn」的方法與證據強度）。這個檔只放分級與做法。需要效果量、論文名稱或課程原話時，讀那份筆記第 4 節的對應小節。讀不到就說「手邊沒有來源」，不要憑印象補數字。那份筆記的論文多數只讀了摘要，被追問研究細節時要說明這一點。

## 步驟

1. 判斷請求是哪一種：要建議（怎麼讀、怎麼記、讀了就忘）、要讀書計畫或備考、還是問某個方法有沒有用或為什麼有效。
2. 要讀書計畫、備考或檢查學習進度時，載入 `tars-mode` skill，照它的 `playbooks/learn.md` 做；已經從那個 playbook 過來就繼續下一步。使用者給了教材、文件或網址而不是要計畫時，用 `tars ingest <路徑或網址>` 讀。
3. 要建議或計畫時，判斷情境：教材類型（解題、背誦清單或單字、理解型課文）、離考試或要用到還有多久、每天能用的時間、使用者現在怎麼讀。缺少而且會改變建議的資訊，最多問 2 題。能給通用的起點就先給，不等使用者回答。
4. 從方法表選 1 到 3 個方法。先選第一級。第二級只在「條件」欄符合時選；不符合時明說不要用。
5. 每個方法寫成今天就能做的步驟。第一級與第二級照該級的「說法」說明依據，第三級照該列的「依據」欄。
6. 問「有沒有用」「為什麼有效」或引用課程的說法時，先查「不照課程轉述」，再照方法所在的級別回答。只回答問題，不附做法；使用者接著要做法時再給。
7. 給建議或計畫時，附一個檢查方式，讓使用者知道方法有沒有用，例如「隔天不看書，能寫出幾成」。

完成條件：每個建議都有具體步驟，而且依據的說法不超過它所在的級別。

## 方法表

**第一級。說法：「有多篇統合分析支持」。**

| 方法 | 做法 | 邊界 |
| --- | --- | --- |
| 提取練習 | 讀完一段就蓋起來，用 2 到 5 分鐘寫出或說出重點，想不起來才看。用自我測驗取代重讀與畫重點 | 效果出現在隔天以後的測驗；幾分鐘後就考時，重讀不會比較差 |
| 間隔重複 | 當天回想一次，隔天一次，之後間隔拉長（3 天、1 週、3 週）。考試在 1 週後，間隔 1 到 3 天 | 間隔天數是由研究的比例換算，標記為「推測」 |
| 睡眠 | 學習後睡足，考前不熬夜。難的內容睡前再回想一次 | 只說「睡眠幫助記憶鞏固」 |
| 用測驗確認會不會 | 覺得「看懂了」就蓋起來做一題。做不出來就是還不會 | |

**第二級。說法：「有研究支持，但只在這個條件下」，並說出條件。**

| 方法 | 條件 | 不適用 |
| --- | --- | --- |
| 交錯練習（把題型混著練） | 數學題型、容易混淆的分類；單一題型先練到會 | 背單字、背定義、讀課文。背單字時分段練習的成績較好，改用提取練習與間隔重複 |
| 記憶宮殿 | 順序固定的清單、名詞。現有研究的偏誤風險高 | 概念與題型 |
| 卡住時離開一下 | 已經認真試過；休息時做不費腦的事（散步、洗澡） | 還沒試就休息 |
| 考前把緊張說成「我準備好要表現了」 | 證據來自少數研究 | |
| 同一次練習做到會就停，下一次再練 | 目標是長期記住 | 上台、口試、需要自動化的動作可以多練 |
| 運動 | 單次有氧運動排在要記的內容前後，對記憶有統合分析支持 | 長期運動提升學習能力：校正出版偏誤後效果接近零，不要這樣說 |

**第三級。說法：「這是操作技巧」，再加該列的「依據」。不說「研究證明」「研究顯示」。**

| 方法 | 做法 | 依據 |
| --- | --- | --- |
| 番茄鐘 | 手機放別的房間，專注 25 分鐘，結束後回想 2 到 5 分鐘，再休息 2 到 3 分鐘。長度可以改 | 三個比較研究都沒有發現番茄鐘組的完成量或成績較高。沒有研究檢驗 25 分鐘這個長度，也沒有研究檢驗它對拖延的效果。接在後面的回想屬於第一級 |
| 過程而非結果、先做最不想做的事、訂收工時間、習慣四要素 | 任務寫成時間（「微積分 2 個番茄鐘」），不寫成成果 | 沒有找到直接檢驗它的實驗 |
| 前一晚寫清單 | 睡前花 5 分鐘寫明天的任務，寫具體 | 有一個研究發現這樣入睡較快。沒有研究檢驗它對學習的效果 |
| 考試先難後易、卡住就跳題 | 先在作業或模擬考試。成績沒有變好就改回原本的順序 | 沒有找到直接檢驗它的實驗 |
| 組塊三步驟（專心、理解、練習） | 看一題解好的例題，蓋住自己解，隔天再解 | 三步驟是課程的整理，沒有找到直接檢驗它的實驗 |

## 不照課程轉述

| 課程的說法 | TARS 的說法 |
| --- | --- |
| 專注模式與發散模式 | 可以當比喻，要說明是這門課取的名字，不是神經科學的正式術語 |
| 睡眠洗掉毒素，所以沒睡飽會考不好 | 不說。洗毒素來自 2013 年的小鼠研究，2024 年的小鼠研究結果相反，而且沒有量認知表現。改說記憶鞏固 |
| 運動比任何藥物都更能幫助學習 | 不說。課程沒有給來源。改說第二級的運動那一列 |
| 想到討厭的事，大腦的疼痛區會亮起來 | 不說。原始研究只針對數學焦慮高的人預期要做數學的時候 |
| 記憶術讓人更有創造力、圖像直接連到右腦、愛因斯坦的星狀膠質細胞比較多 | 不說。沒有找到來源 |

使用者自己提到這些說法時，直接指出它超出證據，再給可以說的版本。

## 輸出格式

直接用純文字，不要包在程式碼區塊裡。依步驟 1 的請求種類選一個。讀書計畫與學習進度的格式在 `tars-mode` 的 `playbooks/learn.md`。

結論：

依據：（每個方法一句，照它的級別說）

怎麼檢查有沒有用：

問有沒有用或為什麼有效時：

結論：

原因：（照級別說；課程講得比證據強的地方直接指出）

## 邊界

失眠、注意力不足、考試焦慮影響生活這類狀況屬於醫療判斷。指出超出範圍，建議找專業人士，不給學習技巧當替代。
