# Learn

## 目的

使用者得到一份每天一行的讀書計畫、一份進度檢查，或一段把某個主題教到會的課程。每個方法都有依據，而且回覆寫明教材讀了多少。

## 前提條件

- 進入：排讀書計畫、準備考試、檢查學習進度、要 tars 教會一個主題或技能、考我、練到熟。
- 不進入：還沒有教材與期限、也沒說要被教的學習起點規劃（例如「我想學 Rust，不知道從哪開始」），用 `coach.md`。
- 不進入：只問某個學習方法有沒有用，用 `learning-how-to-learn` skill。
- 需要 `learning-how-to-learn` skill（方法與研究依據）、`socratic-tutor` skill（劇本 C）與 `tars ingest`（讀教材）。

## 劇本

先依請求選一個劇本，再照下面的步驟做。

| 劇本 | 請求 | 用的 skill |
|---|---|---|
| A 計畫 | 排讀書計畫、準備考試 | `learning-how-to-learn` |
| B 檢查 | 檢查學習進度 | `learning-how-to-learn` |
| C 教學 | 教我、考我、練到熟、幫我學會某個主題 | `socratic-tutor`，複習的依據照 `learning-how-to-learn` |

劇本可以搭配：

- 有期限又要被教：先做 A 排出每天的範圍，再對當天的範圍做 C。
- C 的診斷顯示某個子技能很弱，而使用者有計畫：做 B，把弱的子技能排進後面的日子。

## 步驟

1. 使用者給了教材（檔案、資料夾或網址）時，對每一份執行 `tars ingest <路徑或網址> --save`。沒有給教材就跳過。
2. 劇本 A 或 B 會用到練習題時，在轉好的整份檔案裡搜尋題目與解答的標記（例如「練習題」「模擬試題」「解析」「答案」）。逐章記下題數與有沒有解析。
3. 載入 `learning-how-to-learn` skill。計畫或課程裡用的每個方法都從它的方法表選，依據照它的級別說。
4. 確認會改變內容的資訊：考試或要用到的日期、每天能用的時間、教材類型（解題、背誦、理解型課文）。缺少的最多問 2 題。劇本 C 只問主題範圍與目標程度。
5. 劇本 A 或 B：排計畫或檢查進度，照「輸出格式」回覆。
6. 劇本 C：載入 `socratic-tutor` skill，照它的流程教。有教材時，題目從步驟 1 轉好的教材出。間隔複習的時機照 `learning-how-to-learn` 的方法表。
7. 劇本 C 結束或暫停時，提醒使用者說「save state」，把它輸出的進度區塊存起來，下次用「resume from:」接續。
8. 步驟 2 找到練習題或歷屆試題時，在回覆最後用一句話提議做自我測驗頁。使用者同意後，照 `reference/quiz-page.md` 做。

## 判斷標準

- 步驟 2 不只看目錄。沒有搜尋過的章節寫「沒有確認」，不寫「沒有題目」。
- 步驟 4 要問的超過 2 題時，只問最會改變計畫的 2 題，其餘用假設。能先用假設排就先排，並標明哪些是假設。
- 使用者直接要求測驗頁時，做完步驟 1 與 2 就照 `reference/quiz-page.md` 做。
- 進度落後時先調整範圍，不要求趕進度。讀了就忘時改用提取練習與間隔重複。
- 劇本 C 的程度評定照 `socratic-tutor` 的規則，不放寬。使用者說「just tell me」時只對那一題直接解釋。

## 輸出格式

直接用純文字，不要包在程式碼區塊裡。

排讀書計畫或備考時：

我理解你要準備的是：

教材：（實際讀的檔案與讀了多少；各章的練習題數與有沒有解析；沒有教材就省略）

我會先確認：（最多 2 題，資訊足夠就省略）

計畫：（每天一行，寫成時間與要做的事；考前一晚只做快速回想，正常睡）

依據：（每個方法一句，照它的級別說）

怎麼檢查有沒有用：

自我測驗頁：（步驟 2 找到題目時，一句話提議；沒有題目就省略）

檢查學習進度時：

我理解你現在的進度是：（預計與實際的差距）

建議下一步：

依據：

怎麼檢查有沒有用：

劇本 C：照 `socratic-tutor` 的格式，技能地圖在每次程度改變時重畫。

## 驗證

- 給一份有練習題的教材 → 回覆的「教材」行列出每一章的題數與有沒有解析；沒有搜尋過的章節寫「沒有確認」。
- 沒有給教材 → 回覆沒有「教材」行，沒有執行 `tars ingest`。
- 日期、每天的時間、教材類型都沒給 → 「我會先確認」最多 2 題，其餘寫成假設。
- 計畫用了三個方法 → 「依據」有三句，每句的級別和 `learning-how-to-learn` 的方法表相同。
- 教材有歷屆試題 → 回覆最後一行提議做自我測驗頁；教材沒有題目 → 沒有這一行。
- 「教我 Rust 的 ownership」→ 走劇本 C：先問最多 2 題範圍與目標，再做 3 到 5 題診斷，畫出技能地圖，診斷前不教。
- 「下個月考試，教我第三章」→ 先做 A 排出每天範圍，再對第三章做 C。
- 劇本 C 暫停 → 回覆提醒說「save state」。
