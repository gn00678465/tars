# 自我測驗頁

`playbooks/learn.md` 的步驟 6 用到時讀這個檔。

用途是提取練習：先作答，再看答案。它不是解說頁，不放教材內文的整理。

## 步驟

1. 題目、選項、答案與解析都從轉好的教材照抄，不改寫、不自己出題。
2. 做成一個 HTML 檔，不依賴網路。功能只有這些：選了才顯示答案與解析；可以選來源（哪一章、哪一份試題）；記下答錯的題目，可以只做錯題；顯示這一輪答對幾題。
3. 檔案存在教材所在的資料夾，不放進 repo。
4. 回覆寫檔案路徑、每個來源放了幾題、沒有放進去的題目與原因。

## 判斷標準

- 教材沒有解析的題目寫「教材沒有解析」，不補寫。使用者要求補寫時，標明是 TARS 寫的。
- 答案欄不是單一選項的題目（送分、複選、轉換後看不清楚）不放進測驗，列在頁面最後並寫原因。

## 驗證

- 做完測驗頁 → 回覆列出每個來源放了幾題，和 `learn.md` 步驟 2 記下的題數相同，或寫出差在哪裡。
- 教材有一題沒有解析 → 頁面上那一題顯示「教材沒有解析」。
- 教材有一題是複選 → 那一題不在測驗裡，在頁面最後的清單，附原因。
- 斷網開啟檔案 → 可以作答並看到答案。
